# PIMDesk - Corporate Ticket Management Ecosystem (Desktop & Mobile)

Welcome to the repository for **PIMDesk**, a capstone project developed as part of the Systems Analysis and Development degree at Universidade Paulista (UNIP).

This project is a robust integrated ecosystem—comprising both a Desktop management application and a complementary Mobile app—designed to streamline corporate ticket management, IT support requests, and operational data visualization.

> ⚠️ **Important Notice Regarding Live Data:**
> As this academic project has been successfully concluded, the cloud database hosting and backend API services have been decommissioned. You can still explore the source code, compile the applications, and navigate the visual interfaces (UI/UX) of both the Desktop and Mobile platforms, but live data fetching is currently offline.

## 🛠️ Tech Stack & Architecture

This application was architected focusing on maintainability and system integration across different platforms, utilizing the following technologies:

### Desktop Application
* **Language:** C#
* **Framework:** .NET
* **UI / Presentation:** Windows Forms (WinForms) with deeply customized User Controls
* **ORM / Data Access:** Entity Framework

### Mobile Application
* **Architecture:** Mobile component seamlessly designed to allow end-users to create tickets, track status updates, and interact with the ecosystem on the go.

### Infrastructure & Operations
* **Database:** SQL (Formerly hosted in the cloud)
* **Version Control:** Git & GitHub

## ✨ Key Features

Even operating in a UI-only environment without the live database, the source code showcases several advanced full-stack development concepts:

* **📱 Mobile Accessibility:** A mobile interface designed for quick interactions and ticket status tracking for end-users.
* **📊 Dynamic Desktop Dashboard:** A data-driven analytics panel in the desktop app designed to render charts and metrics regarding ticket statuses and team performance.
* **💬 Integrated Ticket Forum/Chat:** A messaging interface simulating a forum environment for seamless communication on specific support tickets across platforms.
* **🧩 Custom User Controls:** Extensive customization of standard WinForms components to create a modern and intuitive user experience.
